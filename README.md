# Wildmere

A quiet phone-first browser 3D survival valley built with Three.js.

Walk the valley, gather wood and food, plant a little, fish at the bend, rest by a fire, and note the quiet landmarks you find.

## Play
Open index.html in a browser (or serve the folder). On phone: left half walks with the knob, right half looks. On-screen buttons for gather (E), build (F), plant (G), rest (R), notebook (M), cycle build (Tab/Q).

No pointer lock. Family-friendly. Single player.

## Controls
- WASD or left stick: walk
- Right drag: look
- E: gather
- F: build (cycle with Q/Tab)
- G: plant on a soil bed
- R: rest near a fire at night
- M: notebook
- 1: eat

See ROADMAP.md for recent notes.
